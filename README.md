# Beecrowd 1096 - Sequência IJ 2

## Descrição
Programa desenvolvido em Java para imprimir uma sequência de valores das variáveis I e J, conforme solicitado pelo Beecrowd.

## Linguagem
Java

## Entrada
O programa não possui entrada de dados.

## Saída
Imprime a sequência de valores de I e J, com I variando de 1 até 9, de 2 em 2, e J variando de 7 até 5.
